# Q版，cute chibi复古横版手绘游戏宠物/怪物/魔物设计提示词规则

> 本模板适用于游戏内的**宠物、伙伴、召唤兽、野怪、BOSS 级魔物**等生物类角色设计，与「人物设计提示词规则」配套使用。
> 模板骨架与人物版一致，差异点在于：生物类以**物种+体型**替代「国籍+身高」，以**毛发/皮肤/鳞片/羽毛**替代「穿着」，并新增 **性格** 与 **招牌动作** 两个专属维度——这是宠物/魔物立绘最能出彩、也最容易被忽略的部分。

---

## 一、核心基础规范（通用所有生物设计）

1. **画面基底**：纯白纯色背景，无任何装饰、阴影、场景元素，生物独立呈现，画面干净简洁

2. **画风界定**：纯正**复古横版手绘风格**，拒绝矢量扁平画风、3D建模风、厚涂写实风；保留手绘笔触纹理、毛发/鳞片/羽毛的**分层笔触质感**（毛发根根分明、鳞片逐片叠加、羽毛鳞纹清晰），线条柔和不僵硬，带有复古像素手绘、老游戏横版角色的复古质感

3. **生物形态**：Q版比例（头大身小、圆润敦实，适配可爱复古游戏调性），完整全身展示，无裁切、无半身、无局部特写；**尾巴、耳朵、翅膀、犄角等延伸部位必须完整呈现，不得裁出画框**

4. **基础动作**：默认统一为**物种适配的标准站立姿势**，体态放松、四肢自然，无跳跃、奔跑、扑咬、蜷睡等动态动作；四足类四脚平稳着地、双足类竖直站立、禽鸟/飞行类立于木杆或地面、爬行类平贴地面、漂浮类离地悬浮，身姿端正统一，适配游戏生物立绘使用场景

5. **细节要求**：所有生物属性、毛发/皮肤/鳞片/羽毛需**从头到脚、从背到腹极致细化**，无模糊描述、无笼统概括；五官、斑纹、毛色渐变、鳞片排布、肉垫、爪型、尾型、配饰面料与配色全部精准刻画，保证可直接出图

## 二、固定输出格式（必严格遵守）

### 常规单视图（默认）格式

**生物名称：**自定义专属游戏生物名，贴合物种设定、性格特征（如「橘小贼」「懒坨」这类能读出性格的名）

**性格：**一句凝练的性格标签（如：贱兮兮爱偷东西 / 傲娇高冷不爱搭理人 / 热情粘人碎嘴爱哼哼 / 胆小敏感容易受惊 / 臭美自恋总梳理羽毛 / 摆烂佛系随时随地犯困 / 贪财囤货腮帮子塞满零食 / 暴躁炸毛一点就生气 / 温柔黏人喜欢贴贴 / 古灵精怪爱捉弄别的小动物），性格决定神态与后续招牌动作

**动作：**物种适配的标准全身站立，姿态端正放松，正面正对镜头，四肢自然支撑，体态协调统一

**生物属性：**精准标注【物种、性别、年龄、体型、整体外貌特征、神态】，外貌需细化脸型、五官（瞳孔形状颜色、鼻/喙/鼻头形态）、耳朵形态、尾巴形态、斑纹、体态特点，细节完整

**毛发/皮肤/鳞片与配饰细节：**从头到脚、从背到腹全覆盖，包含头部（耳朵内外色、头顶花纹/羽冠/犄角/触角）、脖颈（项圈、围兜、领结、锁链等配饰）、躯干（背部渐变、胸腹毛色、斑纹/鳞片排布、皮肤褶皱）、四肢（爪/蹄/鳍/翼、肉垫颜色、毛尖/鳞尖颜色）、尾部（尾长、渐变、尾型、尾尖色），标注配色、材质、花纹、分层笔触细节，无遗漏

**风格：**复古横版手绘Q版风格，非矢量扁平画风，保留原生手绘笔触与毛发/鳞片分层纹理，柔和手绘线条，经典老游戏横版生物质感，纯白纯色背景，完整全身立绘，画面干净复古治愈

### 三视图+招牌动作专属格式（用户指定三视图时启用，宠物/魔物惯例为「三视图+第四幅招牌动作」）

**生物名称：**自定义专属游戏生物名，贴合物种设定与性格特征

**性格：**一句凝练的性格标签，作为第四幅招牌动作的情绪来源

**视图与动作划分：**1. 左画面\-生物正面、中画面\-纯右侧面、右画面\-生物背面（三视图采用同一种**物种适配的标准站立姿势**，体态完全统一）；第四幅\-单独展示**招牌动作**（由性格衍生的标志性动作，详见「招牌动作设计细则」），与前两幅形成「静态立绘 + 性格高光」对照

**画面位置与视角：**前三幅横向均匀排布，画面间距均等，无重叠、无裁切；招牌动作独立成幅，不与三视图同框，可略放大突出性格细节

**生物属性：**精准标注【物种、性别、年龄、体型、整体外貌特征、神态、性格】，细化脸型、五官、瞳孔、耳朵、尾巴、斑纹、体态，适配三视角展示逻辑

**毛发/皮肤/鳞片与配饰细节：**分视角细化——正面展示胸前/腹部花纹、前侧配饰与五官细节，侧面展示身形轮廓、毛发厚度、鳞片/羽毛层次、侧边配饰，背面展示后背斑纹/鳞片排布、背部配饰、尾根与后肢后侧细节，从头到脚、从背到腹细节全覆盖

**风格：**复古横版手绘Q版风格，非矢量扁平画风，原生手绘笔触与毛发/鳞片分层质感，线条柔和复古，纯白纯色背景，三视图+招牌动作完整生物设计，统一体态统一画风，游戏生物标准三视图与性格高光图

## 三、细节撰写细则（核心硬性要求）

### 生物属性撰写标准

1. **物种**：明确真实动物/虚构怪物/魔物的具体物种及亚种，注明现实原型（如：中华田园橘狸花猫、银渐层英国短毛猫、双色彭布罗克短腿柯基犬、黄化玄凤鹦鹉、灰蓝顺毛荷兰猪、蓝双布偶长毛猫），怪物/魔物可注明能力来源或栖息地

2. **性别**：清晰标注公/母/无性别，匹配体态、毛色、配饰风格（如公猫獠牙短粗、母猫体态纤细）

3. **年龄**：宠物用月龄/岁龄（如 1 岁幼宠、8 个月幼犬、3 岁成年）；怪物/魔物可用「幼体/成体/古体」或岁月跨度，通过体型、眼神、花纹完整度贴合年龄设定

4. **体型**：标注体态关键词（矮胖圆滚滚/纤细小巧/圆胖敦实/迷你团子/修长圆润/短粗壮实/纤细修长），结合 Q 版比例适配整体身形大小

5. **外貌**：细化脸型（圆脸/包子脸/鹅蛋脸/方块脸/尖圆脸等）、瞳孔形状与颜色（琥珀圆瞳/墨绿细瞳/黑圆葡萄眼/冰蓝通透大眼/红棕圆瞳/狭长灵动瞳）、鼻头/喙形态、耳朵形态（三角小耳/软垂长耳/直立狐耳/蝙蝠耳/羽冠）、尾巴形态、斑纹（虎斑/渐变/重点色/大块斑块/三道细纹）、神态表情，整体气质精准描述

6. **性格（生物专属）**：一句话性格标签，直接决定神态走向与招牌动作设计，不得缺失；性格需与物种外形形成反差或呼应（如娇小仓鼠贪财、圆胖柯基话痨、高冷英短只侧抬眼皮）

### 毛发/皮肤/鳞片细节撰写标准（从头到尾、从背到腹全覆盖）

1. **头部**：耳朵内外色（如耳内浅粉）、头顶花纹（深黑 M 型花纹/三道浅灰细纹/大黑斑块/浅灰毛尖）、羽冠/犄角/触角样式、眼周配色、口鼻部毛色（白围脖/口鼻纯白/鼻尖粉/黑圆鼻头）

2. **脖颈**：所有颈饰——项圈、围兜、领结、锁链、脚链，细化样式、配色、材质、挂坠（木质小鱼/珍珠/蝴蝶结/青铜枫叶/迷你铃铛/小胡萝卜绣花）

3. **躯干**：背部毛色渐变（橘黑渐变/深灰渐变/暖黄/浅棕渐变/灰蓝/重点色）、胸腹毛色（腹毛雪白蓬松/胸口雪白无杂色/胸腹全白）、斑纹排布、鳞片/甲壳排列、皮肤褶皱

4. **四肢**：爪/蹄/鳍/翼形态，肉垫颜色（粉粉肉垫/灰蓝粉垫），毛尖/鳞尖颜色（爪尖带浅灰毛尖/爪尖雪白），腿型长短（短粗肉腿/纤细小白腿/前腿黑后腿白）

5. **尾部**：尾长与形状（粗长条纹尾/细长尾/短胖尾/棉花尾/蓬松超大尾/螺旋短尾/卷住小腿的大尾/长尾渐变），毛色渐变（浅灰过渡深灰/浅灰渐变巨大长尾/尾尖一撮纯黑/尾尖一大团纯白），尾型按性格设计（麻花卷/重重甩/左右扭/缩成毛球）

6. **附加质感**：明确毛发/鳞片/羽毛的笔触类型——长毛分层蓬松笔触、短绒毛软糯质感、短硬短毛质感、鳞片逐片叠加、羽毛分层鳞纹，作为风格落地的关键约束

## 四、生物类型适配（宠物 / 怪物 / 魔物差异化要点）

在统一框架内，三类生物在「细节撰写」和「配饰选择」上各有侧重：

1. **宠物**（现实动物 Q 版化）：毛发柔软温暖，配饰亲和可爱——棉织项圈、蝴蝶结、口水巾、围兜、铃铛；配色以暖色、浅色为主，神态多温和或俏皮，画风强调「软糯」「蓬松」

2. **怪物**（奇幻生物）：可叠加现实不存在的元素——犄角、鳞片、甲壳、多足、异色瞳孔、发光花纹、非对称特征；配饰可带奇幻质感——锁链、符文挂坠、骨饰、晶石；花纹可有发光/渐变特效，画风强调「层次叠加」「鳞片甲壳质感」

3. **魔物**（危险/黑暗系）：皮肤或毛发可用深色系、哑光质地，可含发光瞳孔、毒刺、骨甲、破旧绷带、腐蚀边缘等元素；神态多阴鸷、冷漠或狂躁，但**仍须保持 Q 版比例与手绘笔触**，可爱与危险并存才符合复古横版调性；配饰可用粗糙材质——铁环、旧麻绳、破损布条

> 当用户未指明具体是宠物/怪物/魔物时，默认按「宠物」的亲和基调处理；用户点名「怪物」「魔物」时，按对应类别叠加奇幻/黑暗元素。

## 五、画风禁忌条例（严格规避）

1. 禁止矢量扁平风、极简线条风、AI 光滑无笔触画风，必须保留手绘颗粒感与毛发/鳞片/羽毛的分层笔触纹理

2. 禁止深色背景、渐变背景、场景背景、装饰元素，仅允许纯白纯色底（魔物类亦只换配色，不换背景规则）

3. 禁止半身、裁切、局部生物，必须完整全身展示，尾巴/翅膀/犄角不得裁出画框

4. 禁止夸张动态、扭曲体态，默认统一端正站立静态姿势；仅「招牌动作」一幅允许性格化动态，且需符合物种肢体逻辑

5. 禁止毛发/鳞片/皮肤/配饰模糊笼统描述，所有外观细节必须具象、可落地、可直接出图

6. 禁止性格缺失或神态与性格脱节——生物立绘的神态、配饰、招牌动作必须与性格标签自洽（如「傲娇」就不该咧嘴大笑）
