

一、核心矩形装箱库（直接可用）
maxrects-packer（前端最主流、无依赖的 TS 实现，支持旋转、内边距、多图集拆分）
npm 地址：https://www.npmjs.com/package/maxrects-packernpm
max-rects（新版实现，带在线演示，支持多页布局）
npm 地址：https://www.npmjs.com/package/max-rectsnpm
二、plist 文件生成库
plist（最经典的 JS plist 库，支持 XML 格式解析与生成，直接用 build() 方法即可输出标准 plist）
npm 地址：https://www.npmjs.com/package/plistnpm
plist-next（TypeScript 重制版，类型更严谨，适合 TS 项目）
npm 地址：https://www.npmjs.com/package/plist-nextnpm
