# SliceLab - 图像元素拆分器

## 版本信息

**当前版本**: v3.0  
**最后更新**: 2026-07-22

## 简介

SliceLab 是一款专业的图像处理工具,专为游戏开发者、UI设计师和电商运营打造。它可以智能识别并去除纯色背景,自动拆分图像中的独立元素,支持素材库管理、图集打包导出,以及可视化 UI 界面拼装。

### 核心价值

- **智能处理**: 自动检测纯色背景并去除,支持透明图像直接处理
- **高效拆分**: 基于连通区域算法,快速识别并切分独立元素
- **素材管理**: SQLite 数据库管理素材,支持分类、批量改名和检索
- **图集导出**: MaxRects 算法优化排版,支持 Cocos2d plist 格式
- **UI 拼装**: 可视化拖拽拼装游戏 UI 界面,支持多格式图片素材

## 功能特性

  - Bounding Box 计算 + Padding 外扩
  - 输出透明 PNG

### 核心算法

#### 背景去除算法

```
1. 绘制图片到 Canvas,获取 ImageData
2. 取四角像素颜色,投票确定主背景色
3. 遍历像素,RGB 距离 < 容差则 alpha = 0
4. 边缘羽化处理(可选)
```

#### 连通区域标记算法

```
1. 创建 visited 数组标记已访问像素
2. 对每个 alpha > 0 且未访问的像素启动 BFS
3. 收集连通像素,记录 Bounding Box
4. 过滤面积小于阈值的区域
5. 按 padding 外扩 bbox 并裁剪
```

#### 多格式图片尺寸解析

```
1. 读取文件头判断格式(PNG/JPEG/GIF/WebP/BMP)
2. PNG: 读取 IHDR chunk 的 width/height
3. JPEG: 遍历 SOF0/SOF2 marker 读取宽高
4. GIF: 读取逻辑屏幕描述符
5. WebP: 根据 VP8/VP8L/VP8X chunk 解析
6. BMP: 读取 DIB header
```

### 性能优化

- Uint8ClampedArray 直接操作像素
- BFS 迭代实现(避免栈溢出)
- 大图自动缩放(>4000px → 2000px)
- Web Worker 并行处理
- 图片文件存硬盘,数据库仅存元数据(避免数据库膨胀)
- SQLite VACUUM 回收磁盘空间

## 使用流程

### 基本流程

1. **上传图片**: 拖拽或点击上传 PNG/JPG/WEBP/GIF/BMP 文件
2. **设置参数**: 调整背景去除参数和元素过滤条件
3. **自动处理**: 系统自动去背景并拆分元素
4. **预览选择**: 在元素画廊中查看和选择需要的元素
5. **导出下载**: 批量下载选中的元素(ZIP打包)

### 从素材库批量拆分

1. 在工作台点击"从素材库选择图片批量拆分"
2. 在弹窗中多选素材库中的图片
3. 确认后系统自动逐一拆分,结果累积到元素画廊

### 素材库管理

1. 切换到"素材库"标签页
2. 在左侧分类列表选择目标分类
3. 点击"批量导入"上传图片(自动归入当前分类)
4. 使用批量改名功能统一命名(前缀+递增序号)
5. 检索和管理素材

### 图集打包

1. 切换到"图集打包"标签页
2. 从素材库选择需要的元素
3. 设置图集参数(尺寸、间距等)
4. 选择导出格式(PNG + plist/JSON)
5. 生成并下载图集

### UI 界面拼装

1. 切换到"UI拼装"标签页
2. 新建方案或编辑已有方案,进入编辑器
3. 从左侧控件栏添加控件到画布
4. 从右侧素材库拖拽素材到控件
5. 在属性面板调整控件属性
6. 使用对齐分布工具排版
7. 点击保存,可独立预览 UI 效果
